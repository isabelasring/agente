# Leccion 1: Introduccion al analisis geoespacial

El analisis geoespacial consiste en estudiar informacion que tiene ubicacion geografica.

Conceptos clave de esta leccion:
- Capa (layer): conjunto de datos de un mismo tipo, por ejemplo carreteras.
- Coordenadas: pares de valores que ubican un punto en el mapa.
- Buffer: zona de influencia alrededor de un objeto geografico.

Ejemplo:
Si queremos identificar colegios cercanos a un hospital, podemos crear un buffer de 2 km alrededor del hospital y filtrar los colegios dentro de esa zona.
